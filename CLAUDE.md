# Valkompass

## Git commits

- Do **not** add a `Co-Authored-By: Claude ...` trailer to commit messages.
- Do **not** add the `🤖 Generated with Claude Code` line to commits or pull request descriptions.

Write the commit message with just the change description — no co-author or tool-attribution footer.

## Workflow

- Don't commit directly to `main`. Create a feature branch and open a pull request.
- The maintainer reviews and merges PRs manually — don't merge, and don't enable auto-merge.
