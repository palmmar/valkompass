# Ändringslogg – källsättning av partipositioner (2026-06-07)

Jämförelse mellan det ursprungliga **utkastet** och de **källsatta** värdena efter research mot verkliga webbkällor. Av 400 celler ändrades **54 värden**; övriga 346 fick bara källa tillagd (värdet stämde redan). Skala: 4 = håller helt med, 3 = delvis med, 2 = delvis emot, 1 = håller inte med.

**Sammanfattning:** 54 ändrade värden. Maskinläsbar version i `CHANGES.csv`; fullt belägg (ordagrant citat) per cell i `sources.json`.
